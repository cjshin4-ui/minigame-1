# Minigame 1
## Devlog
I relate Components, GameObjects, and Scenes to 3 russian nesting dolls. The smallest doll would be the Components, and it would be inside of the next/2nd doll which would be the GameObjects. Then the GameObjects would be inside of the 3rd and final doll, which would be the Scene.
